# Internationalization (i18n)

## Choice

**next-intl** (v4) with the App Router — officially supports Next.js 16, React Server Components, and locale-aware navigation.

## Locales shipped (v1)

| Code | Language | URL prefix | Direction |
|------|----------|------------|-----------|
| `en` | English (default) | none (`/marketplace`) | LTR |
| `ur` | Urdu | `/ur/...` | RTL |
| `ar` | Arabic | `/ar/...` | RTL |

English stays unprefixed (`localePrefix: "as-needed"`) so existing production URLs keep working. Preference is stored in the `NEXT_LOCALE` cookie (1 year) via next-intl + the header language switcher.

## Scope of v1

Translated chrome only:

- Header nav, auth CTAs, language switcher
- Footer
- Home hero
- Section heroes: Marketplace, Clubs, Blog, Community, Horse Health

Listing titles, DB content, admin copy, and form field labels remain in their source language.

## Layout

Routes live under `app/[locale]/…`. API routes, auth callback/signout, `robots.ts`, and `sitemap.ts` stay outside the locale segment.
