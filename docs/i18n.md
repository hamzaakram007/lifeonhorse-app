# Internationalization (i18n)

## Choice

**next-intl** (v4) with the App Router — officially supports Next.js 16, React Server Components, and locale-aware navigation.

## Locales shipped

| Code | Language | URL prefix | Direction |
|------|----------|------------|-----------|
| `en` | English (default) | none (`/marketplace`) | LTR |
| `ur` | Urdu | `/ur/...` | RTL |
| `ar` | Arabic | `/ar/...` | RTL |

English stays unprefixed (`localePrefix: "as-needed"`) so existing production URLs keep working. Preference is stored in the `NEXT_LOCALE` cookie (1 year) via next-intl + the header language switcher.

## Scope

Translated chrome and shells:

- Header nav, auth CTAs, language switcher
- Footer
- Home hero
- Auth pages (login / signup) labels and CTAs
- Dashboard shells, empty states, and common owner CTAs
- Section heroes: Marketplace, Horses, Products, Services, Sellers, Clubs, Trainers, Events, Courses, Blog, Community, Horse Health / Experts
- Section empty states and FilterBar / ListingCard chrome (Filter, Clear, All countries, photo count, Verified / Featured)
- Offline fallback (`/~offline` and locale variants)

**Not translated:** listing titles, descriptions, and other user/DB-authored content. Admin copy stays English for now. Auth provider error strings are shown as returned by Supabase.

## Message namespaces

| Namespace | Use |
|-----------|-----|
| `Brand`, `Nav`, `Auth`, `Language`, `Footer`, `Home` | Site chrome |
| `AuthPages` | Login / signup forms |
| `Forms` | FilterBar, country select, OwnedList chrome |
| `Common` | Shared CTAs and badges |
| `Heroes` | Section heroes + marketplace tabs |
| `Empty` | List / strip empty states |
| `Dashboard` | Owner dashboard shells and CTAs |
| `ListingCard` | Photo-count chrome |
| `Offline` | PWA offline page |

Catalogs live in `messages/{en,ur,ar}.json`.

## Layout

Routes live under `app/[locale]/…`. API routes, auth callback/signout, `robots.ts`, and `sitemap.ts` stay outside the locale segment.
